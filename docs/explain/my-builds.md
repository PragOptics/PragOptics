# My builds

What you published to the board from the Studio (Export, then Publish as a module).

A finished build is a draft only you see: install it in your own environment to prove it, then submit it for review. You can retract it until an operator decides. A new version of the same module replaces the old one on the board once approved — it waits for review before anyone else sees it, but you can install it in your own environment right away.
